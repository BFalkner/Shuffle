# Working in this repo

## Writing rules

Console replies follow `unslop` only. It is manual-only, so read `.claude/skills/unslop/SKILL.md` directly at the start of a session.

Everything else written here (site copy, docs, write-ups, commit messages) follows three skills. When they disagree, the earlier one in this list wins:

1. `technical-writing`
2. `writing-general`
3. `unslop`

Two exceptions:

- Em dashes follow `writing-general`. Use one rarely, where it reads better than a new sentence, and never more than one in a paragraph.
- Site text uses curly apostrophes and quotes (`&rsquo;`, `&ldquo;`, `&rdquo;` in JSX). Console replies use straight ones.
