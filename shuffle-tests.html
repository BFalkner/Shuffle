Loads shuffle-simulator.html into a hidden frame using an ordinary link navigation (not fetch, which browsers block for local files), then injects its own script a second time inside that frame so it runs in a real, native script scope — the only reliable way to reach let/const declarations, which don't attach as readable properties the way var/function do. No copy of the engine is kept here. One real limitation: a few browsers treat every local file as its own separate origin and block even this; if that happens, the message on screen says so and suggests Firefox or a local web address instead of opening files directly.
